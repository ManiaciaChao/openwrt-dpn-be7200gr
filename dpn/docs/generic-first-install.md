# DPN-BE7200GR 安装与升级

首次安装的目标流程是：**下载 factory-web 镜像 → 原厂后台上传升级 → 等待设备自动安装并重启 → 配置 OpenWrt**。
不需要在电脑上安装 Python、SSH、age，不需要在重启之间打开安装网页或运行脚本。

**版本区别：** 新的 `automatic` 候选实现上述流程，尚待实机验收；已发布的
`dpn-layout4-rc2` 仍是旧的主机辅助安装器，不能用本页步骤安装 RC2。
RC2 请看 [旧版安装流程](host-first-install.md)。文件名相同不代表安装行为相同，
下载时必须核对发行说明中的 `first_install_mode`。

## 首次安装（automatic 镜像）

1. 确认设备为 D-Link DPN-BE7200GR，并下载发行说明标记为 `automatic` 的
   `dpn-be7200gr-factory-web.bin`。需要完整回原厂备份的用户，请在刷机前
   自行按 [可选原厂备份](stock-backup.md) 导出并保管；安装器不执行完整原厂备份。
2. 电脑用网线连接路由器 LAN，断开路由器的 WAN 和其他上联，保持供电。
   登录当前原厂管理地址，在固件升级页面上传该文件一次并确认升级。
   后续分区和写入由设备完成，不需要网页保持连接，不要重复上传或中途断电。
3. 等待自动安装和重启，重新获取电脑的 DHCP 地址，然后访问
   <http://192.168.1.1/>。设置 OpenWrt 管理密码，再配置自己的上网方式和无线。
   初始 WAN、无线关闭；电脑若有其他同为 `192.168.1.0/24` 的连接，应暂时断开，
   以免访问到其他路由器。

原厂管理密码和网络设置不自动迁移。每台设备的校准、MAC、SSH 主机身份和恢复身份
由设备自己的数据或现场随机生成，不在公开镜像中预置。

完整原厂槽和大部分原厂配置会被新布局覆盖。没有刷机前的完整备份，就不能承诺
恢复到原厂的完整状态；独立恢复资料不等于完整原厂备份。

## 后续升级

已安装 layout4 的 OpenWrt，在 LuCI 的“系统 → 备份/升级”上传
`dpn-be7200gr-sysupgrade.bin`，保留设置。不要把 sysupgrade 文件上传到原厂后台，
也不要把 layout4 升级包用于旧 layout3 实验系统。

自动首装会生成每机独立的恢复访问密钥，放在 `/etc/dpn-recovery/access.key`，并纳入
配置备份。安装完成后可通过 LuCI 的“生成备份”导出并私下保管；此操作不影响安装完成，
也不是完整原厂备份。后续升级和物理恢复默认设置会保留该密钥与恢复身份。

当前不支持不保留配置的 `sysupgrade -n`。独立恢复使用静态 LAN `192.168.1.1`
和密钥 SSH，没有 DHCP、无线或 Web；需要已经保存的恢复访问密钥。

## 验证范围

自动安装是新的候选实现，不能继承 RC2 的整流程实机验收结论，也尚无可靠的安装耗时数据。
当前写入资格仍限于已记录的原厂 `260317_1135` / AN7581、FORESEE F35SQB004G
`CD:53:53`、512 MiB、4096+256 页/OOB、256 KiB 擦除块、空 BMT/RAWB、零坏块配置；
其他状态拒绝写入。未做故意物理断电测试。

自动安装内部过程和待验收项见 [实现与验证](automatic-first-install.md)。
